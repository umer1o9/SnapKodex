AI syllabus builder

Six months of activities, written for each child

The syllabus agent turns the curriculum into concrete activities, one subject at a time. It remembers what it has already written, so each new activity builds on the last.

Open the app →Homeschooling overview
Overview

What it does

For each subject, the agent develops a progression that starts at a basic level and deepens to what suits the particular child. Because it is aware of every activity already generated in that subject, it avoids repeats and fills gaps instead of producing a pile of disconnected worksheets.

Generation takes time, so it runs as a background job with live progress. You can watch subjects fill in, and nothing blocks your screen while the agent works.

Preview before it lands

Long generation jobs and bulk changes are shown to you first. The agent proposes; the parent decides what enters the plan.

  • Each activity carries parent instructions in the parent's mother-tongue transliteration.
  • An example walkthrough shows what the activity will look like when run.
  • Scoring configuration, including co-op mode, is part of every activity.

FAQ

Common questions

Can I write my own activities?

Yes. Parents can add or edit activities manually alongside the generated ones.

What happens if I stop mid-generation?

Progress is saved as the job runs, so completed subjects are kept.

Do the activities cover the Arabic and Quran needs of my family?

Quran reading and Noorani Qaida are first-class activity types with their own player features.
